# Healthcare Data Analytics

## Overview

This project was developed as my Bachelor's Thesis and focuses on the analysis of approximately 600,000 anonymized healthcare records using PostgreSQL. The objective was to evaluate diabetes monitoring, disease progression, and quality-of-care indicators through advanced SQL queries and data analysis techniques.

## Dataset

- Approximately 600,000 anonymized patient records
- PostgreSQL relational database
- Clinical data related to diabetes management

## Objectives

- Analyze HbA1c monitoring coverage
- Evaluate disease progression
- Measure quality-of-care indicators
- Identify trends across age, sex, region, and marital status

## Technologies

- PostgreSQL
- SQL
- pgAdmin

## Skills Demonstrated

- Advanced SQL
- Complex Queries
- Data Analysis
- Healthcare Analytics
- Relational Databases
- Data Reporting

## Project Highlights

- Queried and analyzed approximately 600,000 anonymized healthcare records.
- Developed advanced SQL queries to generate clinical and epidemiological indicators.
- Produced analytical reports supporting healthcare research.
